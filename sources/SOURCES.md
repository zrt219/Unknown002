# Sources and Basis Notes

This prompt pack was built around three kinds of source material:

1. The user's spacecraft reference images:
   - notional nuclear-electric spacecraft concept
   - closed Brayton cycle diagram
   - nuclear electric propulsion subsystem/block diagram

2. The uploaded space nuclear policy/analysis documents:
   - `Analysis of the National Initiative for American Space Nuclear Power.pdf`
   - `NSTM-3-2026_04_14-corrected.pdf`

3. Official OpenAI Codex documentation:
   - Codex subagents docs
   - Codex GitHub integration docs
   - Codex Cloud docs
   - Codex best-practices docs

## Key technical ideas used in the prompts

- Use a phased pathfinder concept rather than jumping visually to a giant operational spacecraft.
- Use a common-core reactor-family concept.
- Treat heat rejection and radiator geometry as first-order design drivers.
- Represent closed Brayton conversion with a clear compressor, heat addition, turbine, generator, and heat rejection flow.
- Keep nuclear-electric propulsion visually realistic: small electric thrusters, subtle plume, no chemical flame.
- Keep the long separation boom and shield visually central.
- Avoid claiming the design is flight-qualified.

## Documentation caution

This is a conceptual visualization prompt pack. It does not validate reactor safety, radiator sizing, launch approval, nuclear fuel availability, thermodynamic efficiency, or mission performance.
